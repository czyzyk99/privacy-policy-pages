# Polityka prywatności — Kalkulator drewna

To jest osobne, publiczne repo przygotowane pod GitHub Pages i Google Play Console.

## Co zawiera

- `index.html` — strona startowa z przekierowaniem
- `privacy-policy.html` — właściwa polityka prywatności
- `README.md` — krótka instrukcja publikacji

## Jak opublikować w GitHub Pages

1. Utwórz publiczne repo w GitHub.
2. Wypchnij zawartość tego katalogu na gałąź `main`.
3. Wejdź w `Settings` → `Pages`.
4. Ustaw:
   - `Branch`: `main`
   - `Folder`: `/ (root)`
5. Zapisz zmiany.

Po publikacji adres będzie zwykle wyglądał tak:

```text
https://<twoj-login>.github.io/<twoje-repo>/
```

A polityka będzie dostępna pod:

```text
https://<twoj-login>.github.io/<twoje-repo>/privacy-policy.html
```

## Użycie w Google Play

Wklej publiczny adres polityki prywatności do pola w Play Console.
